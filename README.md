# Pico 2 W IoT 実験ボード

Raspberry Pi Pico 2 W（MicroPython）で、LED・ブザー・人感センサーを動かす学習用リポジトリです。
就職活動用のIoT作品（防犯ライト／温度見守り＋LINE通知）の土台として作っています。

## ハードウェアとピン割り当て
- マイコン：Raspberry Pi Pico 2 W
- LED：赤 GP15、黄 GP14、緑 GP13（それぞれ330Ω）
- 電子ブザー：GP17（NPNトランジスタ 2SC1815 で5V駆動、ベース抵抗1kΩ）
- 人感センサー：Panasonic PaPIRs EKMC1601111（OUT → GP16）

## ファイル
- `blink.py`：LEDの点滅（Lチカ）
- `pir_e9_workaround.py`：人感センサーの読み取り（RP2350-E9の回避策入り）

## 詰まったところと解決：RP2350-E9
**症状**
人感センサーが一度「検知」になると、人がいなくなっても「検知」のまま戻らなかった。

**切り分け**
1. センサーの出力線を外すと0になる → Picoとコードは正常
2. センサーの電源を外すと0になる → 出力線は正しく接続されている
3. 電源をしばらく切ると0から再開するが、検知すると再び張り付く

**原因**
Pico 2 Wのチップ RP2350 のハードウェア不具合「エラッタ RP2350-E9」。
入力ピンが一度Highになると約2Vで張り付き、内部プルダウンでは0に戻せない。
このセンサーは出力電流が最大100μAと小さく、ピンを0に引き戻せなかった。

**解決**
データシートに記載の回避策を、MicroPythonの `mem32` で実装した。
入力バッファ（IE）を普段はOFFにしておき、値を読む瞬間だけONにする。
外付け部品を追加せずに解決できた。
